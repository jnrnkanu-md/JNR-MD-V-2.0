## ✨ Features

| | Feature | What it does |
|:-:|---|---|
| 🗂️ | **Two-level menu** | `.menu` lists the menus, then `.group menu`, `.ai menu`… open each one. `.allmenu` shows everything |
| 🔐 | **Group verification** | Only verified members can post. Others are deleted and tagged to get verified |

| 🐢 | **Account-safe sending** | Cached group info, paced sending and calm reconnects to lower ban risk |

## 🚀 Install in 3 minutes

**You need:** Node.js 18 or newer, and a WhatsApp number to link.

```bash
git clone https://github.com/jnrnkanu-md/JNR-MD-V-2.0.git
cd JNR-MD-V-2.0
npm install
npm start
```

The first start shows a **pair code** (or QR). In WhatsApp open **Linked devices → Link a device** and enter it. When it connects the bot sends **"Bot connected successfully"** to its own chat.

## 🔑 Your keys (`.env`)

Open `.env` in the main folder and paste your keys after the `=`:

```env
GROQ_API_KEY=
FAL_KEY=
```

| Key | Get it at | Powers |
|---|---|---|
| `GROQ_API_KEY` | [console.groq.com/keys](https://console.groq.com/keys) | `.ai`, `.chatbot`, `.agent`, `.stt`, away mode, safety scanner |
| `FAL_KEY` | [fal.ai](https://fal.ai) | `.sora` text to video |

Restart after saving. Never upload a filled-in `.env` to GitHub.

Set your owner number (digits only, with country code), owner name, bot name and prefix in `settings.js`. The default prefix is `.`.

## 🧠 AI, chat agent & away mode

**AI:** `.ai` `.ask` `.gpt` `.chatgpt` `.gemini` `.llama` `.groq` + your question. If a model isn't available for your key, the bot switches to one that is.

**Voice to text:** reply to a voice note with `.stt` (add a language like `.stt yo`, or `.stt translate` for English). `.stt auto on` (owner) converts voice notes people send you privately.

**Chat agent (owner):** teach it your business and it talks to customers like a trained team member.

```text
.agent business Jnr Nkanu Concepts
.agent tone Friendly, professional, short replies
.agent teach Bot activation costs NGN 3,000
.agent faq How long is delivery? | Same day after payment.
.agent all on
```

It answers only from what you taught it, and alerts you when it can't help. `.agent` shows the full guide, `.agent show` shows what it knows.

**Away mode (owner):** `.away on [message]` / `.away off`. Replies in your own writing style, pauses when you write yourself, and never promises anything. Limit it with `.away allow <number>`.

## 🛡️ Group tools

| Command | What it does |
|---|---|
| `.safety on/off` | Scan links, scams, files, pictures, stickers and videos. `.safety status` shows what your key can do, `.scan` checks something on demand |
| `.verification on/off` | Only verified members can post (admins are never checked) |
| `.verify +2349137495210` · `.unverify` · `.verified` | Verify, remove and list members |
| `.welcome on/off/set/reset/preview` | Picture welcome. Variables: `{user}` `{group}` `{description}` `{count}` `{verify}` |
| `.tagall` | Tags everyone (60 seconds between uses) |
| `.vcf` (admins) | Contacts of this group only, each name tagged 🫧ᴶᴺᴿ⁻ᴹᴰ🔥 |
| `.getpp` | Gets and tags a member's profile picture |
| `.antilink` `.antibadword` `.antitag` | Group protection |
| `.ban` `.kick` `.warn` `.mute` `.promote` `.demote` | Member management |
| `.adminalert on/off` | Promote/demote announcements (off by default) |
| `.tostatus` | Post to your status (owner) |

The bot must be a group **admin** to delete messages, remove members or change settings.

## 🛠️ Troubleshooting

| Problem | Fix |
|---|---|
| `.ai` says it isn't set up | Paste your key after `GROQ_API_KEY=` in `.env`, then restart |
| AI says no model is available | In the Groq console, make sure your project can use a chat model |
| Delete / verification does nothing | Make the bot a group admin |
| A download fails | Try again later and read the console lines for each server's reason |
| Settings reset after restart | Your host isn't keeping the `data` folder |
| The bot logged out | Delete the `session` folder, restart and link again |
| "Login open somewhere else" | Another copy is running. Stop it and keep only one |
